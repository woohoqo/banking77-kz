# Терең оқыту негізінде банктік өтініштерді автоматты жіктеу жүйесін әзірлеу

[Ноутбукты Google Colab ортасында ашу](https://colab.research.google.com/github/woohoqo/banking77-kz/blob/main/Banking77_Qazaqsha_Colab.ipynb) · [Курстық жұмыс (Word)](Banking77_Kurstyq_GitHub.docx)

Ағылшын тіліндегі банк өтініші үшін жүйе он санаттың бірін ұсынады немесе оператордың тексеруіне жолдайды. Ноутбук пен Gradio интерфейсі қазақ тілінде.

## Іске қосу

Ноутбукты Colab ортасында ашып, барлық ұяшықты ретімен орындаңыз. GPU қолжетімді болса, оны таңдауға болады. CPU да қолданылады. Кітапханалар, бастапқы деректер мен DistilBERT салмақтары автоматты жүктеледі. Gradio интерфейсі оқыту мен бағалау аяқталған соң ашылады. Colab есептеу ортасына қосылу үшін Google есептік жазбасы қажет болуы мүмкін.

## Курстық жұмыста сипатталған тәжірибе

| Көрсеткіш | Нәтиже |
|---|---:|
| TF–IDF және логистикалық регрессия, таныс санаттар | 374/400 (93,50%) |
| DistilBERT, таныс санаттар | 385/400 (96,25%) |
| Таныс санаттарда автоматты қабылданған жауаптардың дәлдігі | 382/393 (97,20%) |
| Операторға жіберілген өтініштер, толық тест жиыны | 770/3 080 (25%) |

Оқытуға кірмеген 67 санат бойынша 2 680 өтініш тексерілді. Оның 763-і операторға жіберілді, 1 917-сіне қате санат берілді. Курстық жұмыстағы сандар бір іске қосылымға қатысты. Жаңа оқытуда құрылғы мен есептеу ортасына қарай мәндер өзгеруі мүмкін.
