# Терең оқыту негізінде банктік өтініштерді автоматты жіктеу жүйесін әзірлеу

[Ноутбукты Google Colab ортасында ашу](https://colab.research.google.com/github/woohoqo/banking77-kz/blob/main/Banking77_Qazaqsha_Colab.ipynb) · [Курстық жұмыс (PDF)](Banking77_Kurstyq.pdf) · [Word нұсқасы](Banking77_Kurstyq_GitHub.docx) · [Қорғау презентациясы](Banking77_Qorgau.pptx)

Ағылшын тіліндегі банк өтініші үшін жүйе он санаттың бірін ұсынады немесе оператордың тексеруіне жолдайды. Ноутбук пен Gradio интерфейсі қазақ тілінде.

## Іске қосу

Ноутбукты Colab ортасында ашып, барлық ұяшықты ретімен орындаңыз. GPU қолжетімді болса, оны таңдауға болады. CPU да қолданылады. Кітапханалар, бастапқы деректер мен DistilBERT салмақтары автоматты жүктеледі. Gradio интерфейсі оқыту мен бағалау аяқталған соң ашылады. Colab есептеу ортасына қосылу үшін Google есептік жазбасы қажет болуы мүмкін.

Ноутбукты компьютерден ашу үшін Colab мәзірінен **File → Upload notebook** пәрменін таңдап, IPYNB файлын көрсетіңіз. **Runtime → Change runtime type** арқылы GPU таңдауға болады. **Runtime → Run all** пәрмені барлық ұяшықты орындайды. Интернет байланысы қажет.

5-бөлімде модельдердің метрикалары, қателер матрицасы және операторға жолданған өтініштер саны шығады. 7-бөлімде ағылшынша өтініш енгізіп, «Санатты анықтау» батырмасын басыңыз. Сол жерден оқытылған модель архивін жүктеуге болады. Келесі сессияда архивті пайдалану тәртібі есептің Ә қосымшасында берілген.

## Тапсыру файлдары

- `Banking77_Kurstyq.pdf` және `Banking77_Kurstyq_GitHub.docx` – есептің баспа және өңделетін нұсқалары.
- `Banking77_Qorgau.pptx` – қорғауға арналған слайдтар.
- `Banking77_Qazaqsha_Colab.ipynb` – деректерді жүктеу, екі модельді оқыту, бағалау және интерфейсті іске қосу коды.
- `requirements.txt` – Python тәуелділіктері. Colab-та оларды бастапқы ұяшық орнатады.
- `experiment_config.json` – ноутбукта берілген параметрлердің анықтамалық көшірмесі. Оқыту параметрлері ноутбуктағы тиісті ұяшықтарда өзгертіледі.
- `results.json` – курстық жұмыста пайдаланылған CPU сессиясының жинақталған нәтижелері.
